# Step by step Playground tutorial 🤖🧠
---
## Prompt Engineering with GPT-5.5 and the AG News Dataset (Hugging Face)

This tutorial demonstrates how **prompt engineering** influences the quality of responses generated by an LLM.

Unlike the LangChain RAG project, this tutorial focuses **only on the prompting layer** using the **OpenAI Playground**. The retrieved context comes from the same **AG News** dataset used throughout the course.

> **Learning objective:** Learn how different prompts affect grounding, structure, citations, style, tone, ambiguity handling, and response quality without changing the underlying retrieved documents.

---

# Prerequisites

- OpenAI account
- GPT-5.5 access
- OpenAI Playground
- Retrieved documents from the LangChain AG News RAG demo

# Dataset

This tutorial uses the public **AG News** dataset from Hugging Face.

It contains approximately 120,000 historical news articles classified into four categories:

- 🌍 World
- ⚽ Sports
- 💼 Business

https://huggingface.co/datasets/fancyzhx/ag_news/

# Demo 2: Grounded RAG Prompt

## System Prompt

```text
You are a grounded news archive assistant.

Use ONLY the supplied articles.

Rules

• Never use outside knowledge.
• Cite every factual statement.
• Use [Source X].
• If information is missing, say:

"The available archive does not contain enough information."

Response

• Begin with one sentence.

• Three supporting bullets.

• Include category and citation.

• Finish with one limitation.

• Maximum 180 words.

• Professional tone.
```

User Prompt

```text
Retrieved articles

{context}

Question

{question}
```

# Demo 3: Beginner-Friendly Prompt

## System Prompt

```text
You are a teacher.

Explain the retrieved articles to someone with no technical background.

Requirements

• Use simple language.
• Explain difficult words.
• Maximum 3 bullet points.
• Include one example.
• Cite every fact.
• End with

"In simple terms..."

140–180 words.
```

# Demo 6: Ambiguous Question

Question

```
What happened with Apple?
```

System Prompt

```text
If the question is ambiguous,

ask ONE clarification question.

Do not answer until enough information is available.
```

Expected response

```
Are you referring to Apple's financial results,
a product announcement,
or another event?
```

Instead of guessing, the model asks for clarification.

# Key Takeaways

The same retrieved documents can produce dramatically different answers simply by changing the prompt.

Prompt engineering **does not improve retrieval**

Instead, it improves **how the model uses retrieved information**.

A good prompt helps the model:

- stay grounded
- organize information
- adapt to different audiences
- follow a required structure
- acknowledge uncertainty
- avoid hallucinations
